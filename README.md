# SteelLab

철강산업 전문 지식 구독·분석 플랫폼. 스틸데일리 철강연구소의 20여 년 축적 자료(714건)를 주제·필진·기간별로 검색·필터링할 수 있는 메타데이터 카탈로그입니다.

## 사이트 구조

| 페이지 | 경로 | 상태 |
|---|---|---|
| 메인 | `/` | 운영 중 |
| 리서치 아카이브 | `/archive/` | 운영 중 (714건 검색·필터) |
| 프리미엄 리포트 | `/premium/` | 준비 중 |
| SteelLab TV | `/tv/` | 준비 중 |
| 아카데미 | `/academy/` | 준비 중 |
| 세미나·이벤트 | `/events/` | 준비 중 |
| 데이터 센터 | `/data/` | 준비 중 |

## 콘텐츠 정책

본 사이트는 **카탈로그(메타데이터) 레이어**입니다. 각 항목은 스틸데일리 본사이트의 원문 URL로 연결되며, 본문 열람은 스틸데일리 구독 회원 인증을 통해 이루어집니다.

- 사이트가 저장하는 데이터: 제목·필진·날짜·카테고리·원문 URL (사실관계 카탈로그)
- 사이트가 제공하지 않는 것: 기사 본문, PDF 원문

본문 저작권은 스틸데일리에 있습니다.

## 기술 스택

- 정적 HTML/CSS/JS (빌드 단계 없음)
- 데이터: `assets/data/articles.json` (클라이언트 측 필터·검색)
- 호스팅: Netlify (main 푸시 시 자동 배포)

## 로컬 미리보기

```bash
cd <이 디렉토리>
python3 -m http.server 8080
# http://localhost:8080
```

## 배포

`main` 브랜치 푸시 시 Netlify가 자동 빌드·배포합니다.
